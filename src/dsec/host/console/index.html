运行状态的来源

Node 是沙盒运行状态的权威来源。BOUND 表示配额绑定成功，不能据此判断沙盒正在运行。

节点失联时保留最后观测，并停止向它放置新沙盒。失联不代表原沙盒已停止，也不会自动释放配额。

响应丢失后，使用原请求 ID 查询；界面不会自动重新提交操作。
