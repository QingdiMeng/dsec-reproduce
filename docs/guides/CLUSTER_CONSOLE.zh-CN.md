# 集群管理控制台（开发预览版）

[English](CLUSTER_CONSOLE.md) · **简体中文**

可选控制台复用无状态集群 API 和 IAM。所有操作都通过 API，无需直连 etcd、SSH 或 Edge 套接字。控制台不管理模型，也没有自己的沙盒登记库。查看资源指标仍使用 Grafana。先[部署集群](CLUSTER_DEPLOYMENT.zh-CN.md)；证书、IAM、存储和节点须由运维人员配置。

<a id="enable-and-connect"></a>

## 启用并连接

将**控制器**配置中的 `server.console` 设为 `true`。

```json
{"server":{"host":"127.0.0.1","port":8443,"cert_file":"/etc/dsec/api.crt","key_file":"/etc/dsec/api.key","console":true}}
```

将此片段并入现有控制器配置，保留其余部署参数。使用已有入口启动控制器。

```sh
python -m dsec.host.cluster controller --config /etc/dsec/controller.json
```

打开 `https://<certificate-hostname>:8443/console/`。浏览器必须信任 API 的 CA，请保留证书验证。若要求某个控制器故障时控制台仍可访问，在同一 TLS 入口后的每个副本上启用该设置。入口和 CA 由沙盒运行时之外的部署系统管理。浏览器仅向控制台同源地址发送请求，无需跨域 API 或 cookie 会话。此选项仅适用于控制器，默认关闭，节点网关无法启用。静态资源随核心 wheel 分发，无需前端构建工具或运行时依赖。

输入项目 ID 和有效的 IAM bearer 凭据。凭据仅保存在当前页面内存中，不写入 URL、浏览器存储或 cookie；刷新页面需重新认证，退出会清除凭据、结果和所选会话。离开前请复制要保留的请求、沙盒和会话 ID。静态页面可公开访问，读取数据和执行操作均需 API 授权。

<a id="available-pages"></a>

## 控制台页面

| 页面 | 支持的操作和信息 |
| --- | --- |
| 概览 | 项目配额、已用和已委派资源、已配置节点的健康状态 |
| 节点 | 健康、观测过期、不可达或尚未观测的节点；上次观测时间、后端与环境能力以及剩余资源 |
| 沙盒 | 项目内的分配历史、所属沙盒 ID、向节点查询实时状态、创建和停止 MicroVM 或容器 |
| 原生操作 | 选择 MicroVM，打开、重新连接或关闭会话，在预算内执行 shell，预览文件开头 64 KiB |
| 项目与 IAM | 查看当前项目及有权访问的直接子项目，委派资源，变更当前策略，签发或撤销凭据 |
| 请求与审计 | 查询创建请求的准入阶段、配额归属、原请求 ID 和项目审计元数据 |

创建参数需指向节点上已有的环境。JSON 字段沿用 API 参数，MicroVM 使用 `environment_id`，容器使用 `spec`。显式声明的 CPU、内存、磁盘和网络需求必须满足节点设定的可信下限；这些需求不会改变已发布环境的 VM 规格。界面会展示拒绝原因，所有请求仍须通过准入检查。凭据由调用方生成，须先保存再签发。在根项目签发或撤销凭据需要 `iam.credentials`。对子项目的委派和策略修改受祖先项目上限约束。浏览项目需要 `sandbox.read`，查看策略和审计需要 `iam.policy`。根凭据的审计元数据仅对同时具有 `iam.credentials` 的根项目读者可见。按钮按权限显示，后端会独立校验每次调用；读取操作在通过 CAS 返回结果时也会再次核对权限。

<a id="state-and-recovery-semantics"></a>

## 状态与恢复

`ADMITTED`、`DISPATCHED`、`BOUND` 和 `RELEASED` 描述配额及分派归属。沙盒表初始将 guest 运行状态标为 `未查询`。不能根据 BOUND 类型分配的数量推算运行中的沙盒数。`查询状态` 会向所属节点发起查询。失败时显示 UNKNOWN，并单独标出上一次观测；成功时显示观测时间。界面不持续轮询，仅在本地更新观测距今的时间。有效期届满后，原来健康的视图标为 STALE。点击刷新可重新观测。服务端准入始终依据服务端掌握的状态。

节点失联后仍会列出，上次观测的资源标为历史值。Watcher 观测失败或过期时，该节点不能接收新分派，已有配额继续保留。重启的控制器在首次探测前可显示 UNOBSERVED。这个视图可由重新探测生成，健康状态本身不作持久化。

每个变更操作使用一个稳定的请求 ID。调用尚未结束时阻止重复提交；传输失败、响应过大或结果未知时均不会自动重发。查询创建请求时提交原请求 ID，沙盒 ID 留空；查询执行或停止请求还需所属沙盒 ID。DISPATCHED 请求若没有对应的 Edge 日志记录，结果为 UNKNOWN。确认从未准入后，才可以用新 ID 发起下一次尝试。若原控制器地址不可用，打开另一已配置副本或入口，重新认证并用已保存的 ID 查询。IAM 写操作尚无通用的逐请求回执。请通过项目配置、审计记录或凭据身份核实写入结果。

<a id="authorized-browse-api"></a>

## 有权限控制的查询 API

以下操作均使用经认证的 `POST /v1/call` 集群请求封装。

- `project.get` 返回当前项目预算和调用者权限。授权明细仅向策略管理员返回。
- `project.list` 返回有权读取的直接子项目。进入子项目即可向下继续浏览。
- `admission.list` 返回所选项目的创建配额回执，省略创建参数和命令。
- `sandbox.list` 返回绑定到沙盒 ID 的回执，含已释放的历史记录；运行状态为 null。
- `audit.list` 返回所选项目的变更元数据，省略凭据哈希和发生变更的原始键名。
- `node.list` 返回已配置节点及按观测时效计算的健康状态，省略沙盒 ID 和凭据。

列表参数为 `limit`（1–100，默认 50），另可使用 `next_after` 返回的不透明游标 `after`。游标只对当前项目和操作有效，不暴露跳过的项目名。每一页都是单独授权的快照，后续更新可能改变其他页；游标所指记录一旦删除或更改，须重新开始分页。读取时在同一 CAS 边界校验凭据、祖先项目和返回记录。前缀扫描沿用 4,096 条安全上限，超限会显式失败。更大集群须先实现索引或服务端分页。此次变更未涉及 etcd token 续期、未知分派的人工恢复或独立物理宿主机的高可用边界。

<a id="acceptance-boundary"></a>

## 验收范围

可移植回归覆盖项目隔离和敏感字段脱敏、读取返回时撤权、有界分页、过期或缺失的节点视图、创建回复丢失后经另一控制器查询且不重放、释放历史、只读传输分类、可选静态资源服务、精确资源路径和安全响应头。首次浏览器故障验收使用真实 API、IAM、NodeGateway 和显式模拟的 Edge。另一项 Linux 验收使用 Mac 上的两个控制器、独立的三成员 etcd 和真实 Firecracker VM。通过界面创建 VM、打开原生会话、执行命令并读取输出文件，随后经另一控制器重新连接同一会话，最后停止 VM 并确认项目用量归零。仅暂停测试节点网关时，节点标为 UNREACHABLE，历史活动数和配额仍在；网关恢复后 guest 继续运行。这次浏览器使用私有回环 HTTP 入口，节点连接验证 TLS/mTLS；生产浏览器 TLS 入口和独立物理控制面故障域不在本次验收内。静态资源采用严格 CSP，无内联脚本、动态 HTML 注入、CDN 依赖或凭据持久化。原生流式传输、大文件和二进制上传、容器原生会话、全节点实时运行数聚合、配额调整、凭据续期和 OIDC 登录另行开发。文件上传和流式操作可使用现有原生 SDK。
